One brutally honest but still polite out-of-office auto-reply — an entry for make.fun's The Painfully Honest Out-of-Office bounty ($2, top 8 paid).

## Entry

> I'm away from my inbox, which currently holds 3,412 unread emails, and I will answer yours in the order received — politely, and several days later than either of us would like.

## How it works

`main.ts` (Node 22, standard library only) reads the reply from `entry.txt` and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
